> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个严格只读的 Toyota RH850 EPS 探测工具，分层采集 UDS 能力、SA 可用性、MCU/flash 深探信息与 patch 点指纹，输出 JSON + markdown + 下一步 patch 指引。

**Architecture:** comma+panda 上运行，host 侧完成 UDS 枚举、SA、信封上传/触发与流解析；V850 只读 shellcode 从信封请求块读取采集清单，经 CAN TX 流式回传定向区域和寄存器快照；report 根据指纹与 boot integrity 结果输出指引。

**Tech Stack:** Python 3.12、opendbc UdsClient、panda python、pycryptodome(AES/CMAC)、v850-elf-gcc(Docker 交叉编译)

**Spec:** `telescope/docs/superpowers/specs/2026-08-19-rh850-eps-probe-design.md`

### Task 2: protocol.py — 流式协议 + StreamCollector

**Files:**
- Create: `telescope/eps_probe/protocol.py`
- Create: `telescope/tests/test_protocol.py`

**Interfaces:**
- Produces:
  - 帧类型常量（int）：
    `PROTO_VERSION=1`、`FRAME_BEGIN0=0xB0`、`FRAME_BEGIN1=0xB1`、`FRAME_REGISTER_DATA=0xB2`、`FRAME_REGION_BEGIN=0xB3`、`FRAME_REGION_LENGTH=0xB4`、`FRAME_REGION_DATA=0xD0`、`FRAME_REGION_END=0xB5`、`FRAME_EGG_FOUND=0xC1`、`FRAME_EGG_SCAN_END=0xC2`、`FRAME_STATUS=0xC0`、`FRAME_ERROR=0xEE`、`FRAME_END=0xE0`
  - `build_region_request(flags: int, regions: list[tuple[int,int]]) -> bytes`：header magic u32 `0x50524F42` + flags u8 + num_regions u8 + 每项 `{addr u32 BE, len u16 BE}`（10 字节/项）
  - `StreamCollector(expected_version: int = 1)`：
    - `consume(can_id: int, data: bytes) -> None`（data 为 8 字节 CAN 帧；word0=data[0:4] LE，word1=data[4:8] LE）
    - `finish() -> StreamResult`
    - `timed_out` 属性
  - `StreamResult` dataclass：
    - `registers: dict[str, int]`（name → 读值）
    - `regions: dict[int, bytes]`（起始地址 → 已重组的字节）
    - `egg_candidates: list[int]`
    - `dcra: dict[str, int]`（从寄存器表自动挑出 DCRA1*）
    - `prdname: str`（从寄存器表组装 MCU 产品名 ASCII）
    - `combined_crc: int`
    - `valid: bool`（END 帧 CRC 与累计一致）
    - `error: tuple[int,int] | None`（FRAME_ERROR 的 stage/code）
  - `crc32_update(crc: int, byte: int) -> int`、`crc32_stream(bytes_iterable) -> int`

**帧编码（word0 低 8 位 type，高 16 位 slot/序号）：**
- BEGIN0: word0=0xB0|(v<<8)，word1=0；BEGIN1: word0=0xB1|(v<<8)，word1=总帧数预期
- REGISTER_DATA: word0=0xB2|(v<<8)|(slot<<16)，word1=寄存器值；slot 对应 `REGISTER_READS` 下标
- REGION_BEGIN: word0=0xB3|(v<<8)，word1=起始地址；REGION_LENGTH: word0=0xB4|(v<<8)，word1=字节数；REGION_DATA: word0=0xD0|(v<<8)|(idx<<16)，word1=4 字节数据；REGION_END: word0=0xB5|(v<<8)，word1=该区域 CRC（0xFFFFFFFF 求补后）
- EGG_FOUND: word0=0xC1|(v<<8)，word1=候选地址；EGG_SCAN_END: word0=0xC2|(v<<8)，word1=候选数
- STATUS: word0=0xC0|(v<<8)，word1=code；ERROR: word0=0xEE|(v<<8)|(stage<<16)，word1=code
- END: word0=0xE0|(v<<8)，word1=combined CRC
- 所有数据字节进入 CRC 累计（REGION_DATA 的 word1 4 字节 + REGISTER_DATA 的 word1 4 字节），END 校验用 `crc ^ 0xFFFFFFFF`
